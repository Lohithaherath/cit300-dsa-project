# CIT300 Data Structures & Graph Performance Analyzer

Console-based Java application for analyzing data structures, graph traversals, and algorithmic complexity.

## Group Members & Contributions
* **K.H.M.L.C.Herath (22UG3-0274)** - Array & Linked List Data Structures
* **A.I.Athukorala (22UG3-0546)** - Stack & Queue Operations with Exception/Overflow handling
* **A.H.P.M.K. Jayawardhana (22UG3-0736)** - Searching Algorithms & Performance Time Comparison
* **W.YASANTHA (22UG3-0243)** - Graph Adjacency Representation, BFS/DFS Traversals & Main CLI Menu

## Features
- Interactive Console System
- Custom implementation of Array, Singly Linked List, Stack, and Queue
- Performance benchmark between Linear and Binary search (Nanosecond timer)
- Graph operations with BFS and DFS traversals
