## Technologies Used
- **Language**: Java (JDK 17 or higher)
- **Architecture**: Object-Oriented System Architecture
- **Version Control**: Git & GitHub

## Main System Features
1. Array Operations (Insert, Delete, Search, Display)
2. Stack Operations (Push, Pop, Peek, Display with error checks)
3. Queue Operations (Enqueue, Dequeue, Peek, Display)
4. Dynamic Singly Linked List Operations
5. Linear & Binary Search Functionality
6. Undirected Graph Implementation with BFS & DFS Traversals
7. Performance Benchmark Table (Step counts & execution time in nanoseconds)

## Instructions for Running the Program
1. Clone the repository: `git clone <repo-url>`
2. Compile all Java files: `javac *.java`
3. Run the application: `java Main`
